Security Policy

ImageForge by BilvaSoftware

BilvaSoftware takes the security of ImageForge seriously.

If you discover a security vulnerability in ImageForge, please report it responsibly so that it can be investigated and addressed.

Reporting a Vulnerability

Please report security issues privately by email:

bilvasoftware@gmail.com

When reporting a vulnerability, please include:

A clear description of the issue

The affected feature, endpoint, or component

Steps to reproduce the issue

The potential security impact

Screenshots or logs, if useful and safe to share

Any suggested mitigation, if known

Please do not publicly disclose an unpatched vulnerability or publish exploit details before BilvaSoftware has had a reasonable opportunity to investigate and address the issue.

What to Avoid

Please do not:

Access, modify, or delete other users' data

Upload malicious content to a production deployment

Perform denial-of-service or destructive testing

Attempt to obtain credentials, tokens, or private information

Exploit a vulnerability beyond what is necessary to demonstrate the issue

Response

BilvaSoftware will review legitimate security reports and, where appropriate, work to reproduce, assess, and resolve confirmed vulnerabilities.

Response and remediation timelines may vary depending on the severity and complexity of the issue.

Scope

This policy applies to the ImageForge application and its official source code maintained by BilvaSoftware.

Third-party services, hosting providers, dependencies, and external websites have their own security policies and should be reported through their respective channels.
